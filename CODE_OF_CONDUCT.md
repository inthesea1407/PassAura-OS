# Code of Conduct

## Purpose

This project is meant to be a place where people can contribute code, documentation, and ideas without harassment or personal attacks.

## Expected behavior

- Be respectful in issues, pull requests, and discussions.
- Focus on the technical content.
- Accept that decisions will sometimes go against your preference.
- Do not post secrets, personal data, or malware.

## Unacceptable behavior

- Harassment, insults, or threats directed at people.
- Discrimination based on personal characteristics.
- Publishing private information without consent.
- Sustained disruption of discussions.

## Enforcement

Maintainers may warn, restrict, or remove contributors who break these rules.  
Serious or repeated violations can result in a permanent ban from the project spaces.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainers through the private channels listed in the repository (or via GitHub private vulnerability reporting if the issue is security-related).  
Reports will be handled as confidentially as practical.

## Scope

This code of conduct applies to project repositories, issues, pull requests, and any official discussion spaces tied to the project.

This document is a short, practical adaptation of common open-source conduct norms.  
It is not a legal contract.
