# Module 2 (Qwen): Android device-owner app skeleton
Project: PassAura OS (POS), open source (MIT). Goal: an Android app (Kotlin) that runs as device owner and enforces: only PassAura Premium may act as password/credential manager. Zero budget, free tools only, no secrets in files, builds in GitHub Actions (no Android Studio needed).
Build under `android/`: Gradle project (Kotlin DSL, version catalog), module `app` with: DeviceAdminReceiver, a PolicyEnforcer that uses DevicePolicyManager (credential manager policy, e.g. setCredentialManagerPolicy with an allowlist containing only the PassAura package; also block installing other credential-manager apps where the API allows, and disable autofill services other than PassAura via user restrictions or permitted-packages), a first-run screen that registers the device by calling the `register` Edge Function (contract below, URL from BuildConfig, no keys), a settings screen showing registration and premium state. Mark honestly in comments which APIs need device-owner provisioning (adb/QR) and API level. Include unit tests for PolicyEnforcer with a fake DevicePolicyManager wrapper and a GitHub Actions workflow `.github/workflows/android.yml` that runs `./gradlew assembleDebug testDebugUnitTest` on ubuntu-latest.
Touch ONLY: android/** and .github/workflows/android.yml and docs/ANDROID_APP.md.
Contract: Register POST {invite_code, hardware_id_hash(64 hex sha256 of salted hardware id, hashed on device)} -> 200 {device_id}; 403 {error: REGISTRATION_CLOSED|INVITE_INVALID_OR_USED|DEVICE_REVOKED|DEVICE_ALREADY_REGISTERED}; 429 RATE_LIMITED. Redeem POST {code, device_id} -> 200 {premium_until}; 403 KEY_INVALID|DEVICE_INVALID.
Return: a zip or git patch, or code blocks with full paths. State what was not built or run.
